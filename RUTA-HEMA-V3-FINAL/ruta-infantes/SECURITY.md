# Seguridad y alcance DEMO

Este proyecto es un prototipo local para Ruta Hematológica 2026. Usa únicamente códigos ficticios `H-001` a `H-006` y datos de demostración.

## Límites actuales

- No contiene autenticación, backend, base de datos ni cifrado de producción.
- La sincronización utiliza `localStorage` y funciona solo entre páginas con el mismo origen local.
- No debe usarse con datos personales, historias clínicas reales ni para decisiones clínicas.
- Los mensajes del niño son señales de comunicación y no constituyen diagnósticos.

## Reportar un problema

No publiques secretos ni datos personales. Documenta el problema, los pasos para reproducirlo y el archivo afectado, y comunícalo al equipo responsable del proyecto antes de distribuir la demo.
